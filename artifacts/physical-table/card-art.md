# Physical tabletop card artwork

Generated with the built-in ImageGen tool on 2026-09-08, one independent generation per asset. No external API key or CLI image-generation provider was used. The original illustrated locomotive remains unchanged.

All generated sources were 1024 × 1536 PNG. Final project assets were downsampled to 640 × 960 and converted to WebP at quality 87 with `cwebp`; no upscaling, recoloring, cropping, or painting was applied. All nine originals were visually inspected for complete non-powered car silhouettes, coherent engraved style, absence of text/counts, and correct color. The navy reverse is flat artwork; UI supplies card thickness, stack, and shadow.

The two requested Desktop reference files were absent at execution time; the attached images in the conversation supplied the visual reference. Existing `carriage.webp` and `locomotive.webp` were inspected as style context. The new navy reverse follows the supplied mountain-and-rails concept; it is a newly drawn engraving, not a pixel copy.
