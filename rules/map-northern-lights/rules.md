# Northern Lights

[rulebook PDF](rules.pdf) · [map reference](northern-lights-map.png) · [source metadata](sources.json)

Original implementation brief; consult the PDF for complete rules and edge cases.

A standalone Nordic map supporting up to five players, with four bonus objectives selected for each game. Includes tunnels, ferries, special long routes, and its own locomotive rules. Treat bonus-card selection and scoring as data-driven objectives and validate every route-specific exception.
