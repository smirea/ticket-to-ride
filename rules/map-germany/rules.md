# Germany

[rulebook PDF](rules.pdf) · [map reference](germany-map.png) · [source metadata](sources.json)

Original implementation brief; consult the PDF for complete rules and edge cases.

Germany combines route building with passengers collected when connecting cities. Endgame passenger color majorities and completed-ticket bonuses supplement ordinary scoring. This edition is distinct from both Märklin's moving passengers and the original passenger-free Deutschland release.
