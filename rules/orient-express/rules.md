# Orient Express

[rulebook PDF](rules.pdf) · [map reference](orient-express-map.png) · [source metadata](sources.json)

Original implementation brief; consult the PDF for complete rules and edge cases.

Six additional Europe destination tickets. The bundled anniversary rulebook explicitly permits adding these bonus tickets to Classic or its listed variants. The local PDF is that shared rulebook, not a standalone promo leaflet. Acquire the actual six card faces before implementing the deck.

Read first: [europe-classic](../europe-classic/rules.md).

Map reference: Expansion has no separate geographic board. See base entry provenance.
