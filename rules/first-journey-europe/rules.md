# First Journey Europe

[rulebook PDF](rules.pdf) · [map reference](first-journey-europe-map.png) · [source metadata](sources.json)

Original implementation brief; consult the PDF for complete rules and edge cases.

The European First Journey board uses the simplified ticket-completion race. Geographic data and tickets differ from the USA version. Implement immediate ticket completion, replacement draws, the east-west bonus, and the final train-supply condition from this edition.
