# First Journey Usa

[rulebook PDF](rules.pdf) · [map reference](first-journey-usa-map.png) · [source metadata](sources.json)

Original implementation brief; consult the PDF for complete rules and edge cases.

A simplified North American game focused on completing tickets rather than accumulating route points. Completing a ticket triggers replacement, and players race toward the required number of completions. Implement the coast-to-coast bonus, unusable-ticket replacement, and early exhaustion ending.
