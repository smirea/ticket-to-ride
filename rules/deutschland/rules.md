# Deutschland

[rulebook PDF](rules.pdf) · [map reference](deutschland-map.png) · [source metadata](sources.json)

Original implementation brief; consult the PDF for complete rules and edge cases.

The original German-language Deutschland game uses the German map without Märklin's moving-passenger system. It has short and long ticket decks. Keep this 2012 ruleset distinct from Germany and the later Deutschland reissue that integrates the 1902 passenger expansion.
