# Märklin

[rulebook PDF](rules.pdf) · [map reference](marklin-map.png) · [source metadata](sources.json)

Original implementation brief; consult the PDF for complete rules and edge cases.

Passengers can travel through an owned network to collect descending-value merchandise tokens. Passenger cards enable specified use of other players' routes. Special locomotives have route-length restrictions. Model passenger placement, one-use journeys, merchandise stacks, and the completed-ticket bonus.
