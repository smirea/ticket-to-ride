# London

[rulebook PDF](rules.pdf) · [map reference](london-map.png) · [source metadata](sources.json)

Original implementation brief; consult the PDF for complete rules and edge cases.

A compact bus map whose numbered districts reward completing every location in a district. District completion is a separate condition from destination-ticket completion. Use this edition's bus supply, transport deck, route scores, and short-game setup.

Map reference: Visual reference, not verified graph data. Some photos include placed pieces.

Before implementation: Complete destination/card inventory and machine-readable route graph have not been transcribed or verified.
