# Track Switcher

[rulebook PDF](rules.pdf) · [map reference](track-switcher-map.png) · [source metadata](sources.json)

Original implementation brief; consult the PDF for complete rules and edge cases.

A solo logic puzzle rather than a route-building multiplayer map. A puzzle card defines the arrangement of locomotives and wagons; legal moves rearrange them into the requested order. The reference image shows the puzzle tray. The full challenge deck is required to implement all puzzles.

Before implementation: Full challenge deck is not included. Complete destination/card inventory and machine-readable route graph have not been transcribed or verified.
