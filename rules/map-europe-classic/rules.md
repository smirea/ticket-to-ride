# Europe Classic

[rulebook PDF](rules.pdf) · [map reference](europe-classic-map.png) · [source metadata](sources.json)

Original implementation brief; consult the PDF for complete rules and edge cases.

Classic Europe introduces ferry locomotive requirements, uncertain tunnel costs, and stations that can borrow another player's route for tickets. Initial long tickets have a different distribution from regular tickets. Station use must not make borrowed routes count toward the longest continuous path bonus.
