# Card Game

[rulebook PDF](rules.pdf) · [map reference](card-game-map.png) · [source metadata](sources.json)

Original implementation brief; consult the PDF for complete rules and edge cases.

A standalone card game with no geographic board. Players manage a visible railyard and concealed on-the-track piles, collecting colors toward destinations. Card movement, interference with opponents, station bonuses, and end-of-round ticket scoring require a separate game engine.

Map reference: No geographic map: complete railyard, hand, and on-the-track layout diagram.

Before implementation: Complete destination/card inventory and machine-readable route graph have not been transcribed or verified.
